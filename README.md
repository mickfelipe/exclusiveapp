# exclusiveapp

Skill para Claude Code e Codex que guia pessoas leigas, passo a passo e de forma visual, a criar o próprio app ou sistema do zero. Captura o tom de voz da marca, aceita o briefing da plataforma Exclusive Closer (PDF ou campo a campo) e só avança quando cada resposta necessária foi dada.

Instalação: veja [INSTALAR.md](INSTALAR.md). Uso: abra o Claude/Codex dentro da pasta do seu app e diga "quero criar um app".
